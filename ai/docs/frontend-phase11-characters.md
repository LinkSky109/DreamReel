## 1. 完成范围

| 能力 | 实现 |
|---|---|
| 角色列表 | 姓名、别名、群体标记、Provider、审核状态、描述 |
| 角色卡 | 按 schema 分组渲染非空字段（基础/能力/关系/创伤/信念/秘密/结局/声线） |
| 抽取 | LLM / 启发式引擎切换；「生成角色（新备选）」 |
| 联合抽取 | 「角色+世界观（一次·一致）」 |
| 进度 | 轮询 `/extract/status`，按合并/角色/世界观展示任务与完成率，结束后自动停止 |
| 备选集合 | 显示数量/来源/当前项，可切换；失效集合禁用 |
| 审核 | 单角色「通过」，显示已通过数与修订率 |
| 修订 | 弹层选择字段（含姓名）并编辑内容，保存后刷新角色卡与修订率 |
| 锁定 | 进入世界观及之后阶段后，抽取/修订/通过/切换全部禁用并显示「已锁定」 |
| 空/错/加载态 | 无角色引导先摄取再生成；加载骨架；错误重试 |
