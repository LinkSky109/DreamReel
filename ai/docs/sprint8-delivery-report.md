## 二、功能详情

### R14 素材商城
- **7 个内置素材包**：
  - 风格包：诺兰叙事、韦斯·安德森配色（¥19）、日系动漫（免费）
  - 模板包：电商带货（¥29）、故事短片（免费）
  - 音效包：电影级配乐音效（¥39）、Lo-Fi 氛围（¥15）
- 每个包含名称、类型、图标、描述、内容项数、作者、价格
- **分类筛选**：全部 / 风格包 / 模板包 / 音效包
- **购买/领取**：生成订单记录（orderId、价格、时间），免费包价格为 0
- **重复购买拦截**：已拥有的包再次购买报错
- **我的资产**：已购素材包网格、累计拥有数与累计价值，已拥有状态标识
- 前端商城页 `#/store`：素材市场 / 我的资产两个视图切换

## 五、已知限制与后续建议

1. **支付为模拟**：当前购买直接成功，未接入 Stripe/微信支付/支付宝；真实支付、退款、发票待接入。
2. **素材包内容为元数据**：包内风格/模板/音效尚未与实际生成逻辑和素材文件打通，购买后需能真正一键应用。
3. **无创作者上架/分成**：素材包目前为官方/标注作者，暂不支持第三方创作者上架与销售分成。
4. **无评价/评分/销量排序**：可补充包评价、销量与推荐。
5. **授权与 DRM**：付费素材的使用授权范围、跨设备/账号使用规则待明确。
6. 其余历史限制保持不变。
