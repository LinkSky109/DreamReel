## 1. 从原型直接取用

- 复制 5 张封面到 `public/media/covers/`：聊斋志异、西游记、镜花缘、儒林外史、呐喊。
- 列表按书名自动匹配封面；无匹配时保留深色字封面。

## 2. 新增能力

### 章节阅读与段落标记

- 点击左侧章节打开真实正文（`GET /novels/:id/chunks`）。
- 点击段落切换「分镜素材」标记；再次点击取消。
- 标记持久化到 NovelProject `marks`，刷新后保留。
- 左侧章节显示标记数量徽标；右侧概览显示总标记数。

### 审校检查器

- 点击左侧角色/世界观实体，右侧切换为审校检查器。
- 角色状态：待审 / 已确认 / 需修订；世界观：待审 / 已确认 / 需修订。
- 支持审校备注并保存。
- 「全部确认」一次确认全部角色与世界观实体。
- 概览面板实时更新已确认数量。

### 工作台细节

- 左栏角色状态点：已确认绿色、需修订红色、待审灰色。
- 世界观实体状态点同步。
- 章节/角色/世界观列表均来自真实数据。

## 3. 后端兼容

新增接口（均写入真实存储）：

- `POST /api/novels/:id/marks/toggle` — 切换章节段落标记，返回最新 marks。
- `PATCH /api/novels/:id/characters/:cid/review` — 角色状态 + 备注。
- `PATCH /api/novels/:id/world/entities/:eid/review` — 世界观状态 + 备注。
- `POST /api/novels/:id/review/confirm-all` — 全部确认。

模型新增字段：

- `NovelProject.marks`
- `NovelCharacter.note`（状态支持 `revision`）
- `WorldEntity.status` / `WorldEntity.note`

## 4. 真实浏览器验证

用「聊斋志异」真实项目（3 章、3 角色）：

1. 列表显示 `/media/covers/liaozhai.svg` 封面、3 章、3 角色、77 字。
2. 打开第一章，点击首段 → 段落高亮，章节徽标 `1`，概览「段落标记 1」。
3. 刷新后标记仍在（API 返回 marks）。
4. 点击角色「宋公」→ 审校检查器；设为「需修订」，保存备注「核对宋公年龄」→ API 返回 `revision` + 备注。
5. 返回概览 → 「全部确认」→ 3 个角色全部 `approved`，概览「已确认 3/3」。
6. 375px 无横向溢出；概览抽屉可开合。
7. 删除测试项目后空列表正常。

1. 原型角色卡/世界观是“卡片选择 + 八大类可编辑档案”，我们仍以现有 Tab 卡片呈现，未改成原型双栏档案布局。
2. 原型的「章节审校 + 转为分镜」流程尚未串成一步；分镜标记已存，但尚未把标记段落直接转成分镜。
3. 原型列表的 `tagline / dynasty / 状态` 部分为演示字段；真实数据用风格名/分类/阶段推导。
4. 项目库与工作台整体仍未按原型重排（下一阶段）。
