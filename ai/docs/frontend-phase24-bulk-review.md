## 1. 新增能力

### 角色 Tab

- 每张卡新增选择框
- 跨页保留选择（翻页不丢）
- 「全选筛选结果」支持一次选择当前搜索/状态下的全部角色
- 批量操作：通过 / 需修订 / 设为待审 / 清除选择
- 顶部显示已选数量

### 世界观 Tab

- 每张实体卡新增选择框
- 新增审校状态筛选：全部 / 待审 / 已确认 / 需修订
- 同样支持跨页选择、全选筛选结果、批量确认/修订/待审

### 后端

`POST /api/novels/:id/review/bulk`

```json
{ "kind": "characters|world", "ids": ["..."], "status": "approved|confirmed|revision|pending" }
```

- 校验状态枚举与小说归属
- 返回 `{ updated }`

## 3. 已知限制

1. 批量状态修改不可撤销。
2. 全选筛选结果会一次提交数百个 ID；当前请求体可接受，但未做分批。
3. 世界观批量只在有实体时可用；开发数据启发式抽取可能为空。
4. 批量操作没有备注输入（备注仍走单条审校检查器）。
