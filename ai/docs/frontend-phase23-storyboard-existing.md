## 1. 新增能力

### 送入项目弹层

- 「新建项目」：可编辑项目名称，默认 `《书名》· 分镜板`
- 「追加到已有项目」：从项目列表选择目标项目，显示现有镜头数
- 确认后跳转 `/project/:id?tab=shots`

### 去重与来源

- Shot 新增 `sourceNovelId` / `sourceStoryboardId`
- 同一小说、同一分镜草稿重复送入时自动跳过
- 导入响应返回 `{ shots, skipped, total }`
- 项目镜头保留来源引用，便于后续追溯

### 后端

`POST /api/novels/:id/storyboard/import`

- `{}` → 新建项目
- `{ projectId }` → 追加到已有项目
- 重复草稿跳过；没有新增镜头时不重复写盘

## 2. 真实接口验证

临时项目「E2E 去重测试」（2 章、2 个标记）：

1. 首次导入 → 新建项目，`shots: 2 / skipped: 0`
2. 再次导入同一项目 → `shots: 0 / skipped: 2`，项目仍只有 2 个镜头
3. 新建空项目「E2E 已有项目」→ 追加导入 → 项目得到 2 个镜头，且 `sourceStoryboardId` 已写入
4. 临时项目与小说已删除；「殖装」未改动
