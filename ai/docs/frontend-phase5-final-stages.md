## 1. 完成范围

### E-09 AI 影评（React）

- 触发分析（异步 202）→ 2s 轮询，完成后自动展示。
- 综合评分 + 四维评分（镜头语言 / 叙事结构 / 节奏控制 / 角色一致性）。

- 明确展示后端降级提示（如“基础模式分析（LLM 未接入或调用失败）”）。

### E-10 协作（React + 分享页）

- 评论：发布、关联镜头、标记解决 / 重新打开、删除、昵称。
- 统计：总数 / 已解决 / 待处理。
- 分享：公开访问、允许评论、保存、生成并复制链接。
- 新增 `#/share/:token` 只读分享页：项目标题、简介、统计、镜头列表与视频（带 share token 访问受保护媒体）。
- 无效 token / 未公开时显示明确错误页。

### E-11 版本（React）

- 保存版本（名称 / 说明）；版本列表（版本号、时间、镜头/已完成/角色、自动标记）。
- 版本对比：选择两个版本，展示名称/剧本/风格/镜头/角色差异。
- 回滚：二次确认 → 后端先自动备份当前状态 → 恢复目标版本 → 页面重新加载。
- 删除版本：二次确认。

### E-12 项目设置（React）

- 名称、画幅、目标时长、视觉风格、标签；保存后顶栏标题即时同步。
- 全局设置与模型配置入口；分享/角色一致性说明。
- 删除项目（移入回收站）二次确认。

### E-00 AI 助手（React）

- 右下浮动按钮 + 面板：对话历史、快捷问题、输入发送、清空、Esc 关闭。
- 真实调用 `/api/ai-assistant/*`；不做假回复。

### 后端修复

- **版本对比路由被 `/:versionId` 抢占**：`GET /versions/compare` 之前返回 404。已将 compare 路由移到 `/:versionId` 之前。

## 4. 未完成 / 已知限制

1. **旧版音频高级能力**：BGM / 音效素材库、混音预听、字幕样式、声音复刻仍在旧版入口。
2. **AI 助手**：支持对话与快捷问题，但无流式输出、无消息持久化到项目（服务端内存会话）。
3. **版本对比**：字段级差异，不是逐行 diff；回滚会整页刷新。
4. **分享页**：只读展示，仍带应用外壳；未做独立无导航布局。
5. **受保护媒体**：匿名用户无法预览图片/视频，分享页通过 `?share=` 放行。
6. **首屏体积**：单包 626KB（gzip 188KB），尚未路由级拆包。
