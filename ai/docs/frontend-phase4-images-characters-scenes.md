## 3. 未完成 / 已知限制

1. **受保护媒体**：`/storage/images`、`/storage/videos` 等需要登录凭证；匿名用户只能看到占位提示。这是既有安全策略，未在本轮放宽。
2. **需要登录的动作**：创建角色、锁定角色、创建自定义场景（后端 `authRequired`）。匿名流程会明确提示，不会伪造成功。
3. **场景镜头生成未验证**：当日视频额度 5/5 已用完，新增场景镜头只验证了持久化与分镜数据，未实际生成视频。
4. **角色一致性评分 / 造型编辑**：后端有 evaluate / styling 接口，但角色模型无评分字段；本轮未提供 UI。
5. **图片风格**为前端固定 5 种，未读取 Provider 模型目录。
6. **剩余 4 个 legacy 阶段**：AI 影评、协作、版本、项目设置。
