DreamReel API 文档

梦卷 AI 短片创作平台的完整 API 接口文档。基础 URL：http://localhost:3000/api

简介

DreamReel API 采用 RESTful 设计，所有请求和响应均使用 JSON 格式。默认使用 Mock 模式，无需 API Key 即可体验全部功能。

Mock 模式：默认视频/LLM/TTS 均使用 Mock Provider，生成的视频为占位视频。如需接入真实模型，请设置环境变量 VIDEO_PROVIDER、LLM_PROVIDER、TTS_PROVIDER。

认证

API 支持两种访问模式：

  • 未登录：自动使用 default 用户，适合快速体验
  • 已登录：在请求头中携带 Authorization: Bearer <token>

错误处理

错误响应格式统一为：

{
  "error": "错误描述信息"
}

项目管理

GET /api/projects
获取项目列表，支持搜索、筛选、排序和分页。
参数类型必填说明
searchstring可选按名称/描述搜索
statusstring可选all / in-progress / completed / empty
stylestring可选风格 ID 筛选
platformstring可选landscape / portrait / square
sortstring可选updatedAt / createdAt / name
limitnumber可选每页数量，默认 50
offsetnumber可选偏移量
{
  "total": 42,
  "items": [
    {
      "id": "uuid",
      "name": "我的项目",
      "style": "nolan",
      "shots": []
    }
  ]
}
POST /api/projects
创建新项目。
{
  "name": "火星探险",
  "description": "项目描述",
  "style": "nolan",
  "platform": "landscape"
}
GET /api/projects/:projectId
获取项目详情。
PUT /api/projects/:projectId
更新项目信息。
DELETE /api/projects/:projectId
删除项目及其关联的视频、音频文件。
POST /api/projects/:projectId/favorite
切换项目收藏状态。返回 { projectId, isFavorite }。
POST /api/projects/:projectId/archive
切换项目归档状态。归档项目默认不在列表中显示。返回 { projectId, isArchived }。
POST /api/projects/:projectId/duplicate
复制项目（深拷贝剧本/角色/镜头/场景）。镜头状态重置为 pending，不复制视频文件。Body: { newName? }。
POST /api/projects/batch/delete
批量删除项目。Body: { projectIds: string[] }。返回 { success: [], failed: [] }。
POST /api/projects/batch/archive
批量归档/取消归档。Body: { projectIds: string[], archive: boolean }。
POST /api/projects/batch/favorite
批量收藏/取消收藏。Body: { projectIds: string[], favorite: boolean }。
GET /api/projects/tags
获取所有项目标签列表。

项目导入/导出

GET /api/projects/:projectId/export
导出项目为 JSON 文件下载。包含剧本、角色、镜头、场景等完整数据。
POST /api/projects/import
从 JSON 文件导入项目。导入的镜头状态重置为 pending，需重新生成视频。

请求体为导出的 JSON 文件内容（或 { projectData: {...} } 格式）。

剧本生成

POST /api/script/generate
AI 生成完整剧本，包含分镜、角色、旁白。
{
  "idea": "一个机器人在太空站觉醒",
  "targetDuration": 60,
  "style": "nolan",
  "platform": "landscape",
  "projectId": "uuid"
}
POST /api/script/revise
根据反馈修改剧本。

视频生成

POST /api/video/generate
生成单个镜头视频。
POST /api/video/generate-all/:projectId
批量并行生成所有未完成镜头（默认 3 并发）。异步任务，返回 202 后轮询项目状态。
并行生成：通过 VIDEO_MAX_CONCURRENT 环境变量调整并发数，默认 3。

角色管理

POST /api/characters
创建角色。
POST /api/characters/:id/lock
锁定角色（添加参考图），用于保持多镜头一致性。
POST /api/characters/:id/evaluate
评估角色一致性评分。

配音字幕

POST /api/dubbing/generate
为项目生成多语种配音和字幕。
GET /api/dubbing/voices
获取可用音色列表。

风格迁移

GET /api/styles
获取所有可用导演风格预设（10 种）。
GET /api/styles/:styleId
获取风格详情，包含视觉特征和 prompt 修饰词。

模板市场

GET /api/templates
获取所有内置模板（6 个）。
POST /api/templates/:templateId/create
从模板创建项目，可自动生成剧本。

AI 影评分析

POST /api/analysis/:projectId
AI 分析项目的镜头语言、叙事结构、节奏控制、角色一致性，给出专业级反馈。
GET /api/analysis/:projectId
获取缓存的分析结果。

协作共创

GET /api/collaboration/:projectId/comments
获取项目评论列表。
POST /api/collaboration/:projectId/comments
添加评论。
GET /api/collaboration/:projectId/activities
获取项目活动记录时间线。
POST /api/collaboration/:projectId/share
设置项目分享（公开/私有）。

版本历史

GET /api/projects/:projectId/versions
获取项目版本列表（按时间倒序）。
POST /api/projects/:projectId/versions
手动保存当前版本。
POST /api/projects/:projectId/versions/:versionId/rollback
回滚到指定版本（回滚前自动备份当前状态）。
DELETE /api/projects/:projectId/versions/:versionId
删除指定版本。

用户认证

POST /api/auth/register
用户注册。使用 scrypt 密码哈希，零依赖 JWT。
POST /api/auth/login
用户登录，返回 JWT Token（有效期 7 天）。
GET /api/auth/me
获取当前用户信息。

订阅付费

GET /api/subscription/plans
获取所有订阅计划（免费/基础/专业/企业）。
GET /api/subscription/current
获取当前订阅状态。
POST /api/subscription/subscribe
订阅/升级计划（当前为模拟支付，Stripe 接入预留）。

额度管理

GET /api/quota/:userId
获取用户额度使用情况（视频生成次数、配音时长）。
GET /api/quota/me
获取当前登录用户的额度。

数据统计

GET /api/stats/dashboard
获取完整仪表盘数据（概览/趋势/风格分布/额度/最近项目）。
GET /api/stats/trend?days=14
获取创作趋势数据。

通知系统

GET /api/notifications
获取通知列表。支持 ?unread=true 筛选未读，?limit=20 限制数量。
GET /api/notifications/unread-count
获取未读通知数量。
POST /api/notifications/:id/read
标记单条通知为已读。
POST /api/notifications/read-all
标记所有通知为已读。
DELETE /api/notifications/:id
删除单条通知。
DELETE /api/notifications
清除所有通知。

内容审核

POST /api/moderation/check
审核文本内容。Body: { text: string }。返回 { passed, level, categories, details }。
POST /api/moderation/check-batch
批量审核文本。Body: { texts: string[] }。
GET /api/moderation/stats
获取内容审核统计数据。
GET /api/moderation/logs
获取审核日志。支持 ?limit=50。

Provider 配置

GET /api/providers/status
获取当前 Provider 配置状态，包括视频/LLM/TTS 的当前 Provider、可用列表、API Key 配置状态。
GET /api/providers/available
获取所有可用 Provider 列表。视频: mock/runway/pika；LLM: mock/openai；TTS: mock/elevenlabs。

系统信息

GET /api/system/info
获取完整系统信息：应用版本/运行时长、Node 版本、OS/CPU/内存、存储使用、当前配置。
GET /api/system/health
健康检查。返回 { status, timestamp, uptime }。
