# DreamReel / 梦卷 — 产品需求文档（PRD）

> 版本：v0.1（MVP 需求设计稿）
> 日期：2026-09-29
> 状态：需求评审中

---

## 一、产品定位

### 1.1 一句话定义

DreamReel 是一款面向独立创作者和小型团队的 AI 短片创作平台——从一句话想法到成片输出，覆盖剧本、分镜、生成、配音、字幕全链路，核心解决"AI 视频角色/场景不一致"和"创作流程碎片化"两大痛点。

### 1.2 产品愿景

让每个人都能像做梦一样拍电影——降低专业视频创作门槛，使单人创作者也能产出具有电影感的连贯叙事短片。

### 1.3 名称释义

- **Dream**：AI 生成像做梦一样，想象力无边界
- **Reel**：电影胶片卷，象征专业影像与叙事传承

## 二、目标用户与场景

### 2.1 核心用户画像

| 画像 | 特征 | 核心诉求 | 付费意愿 |
|------|------|----------|----------|
| 独立短片创作者 | 有影视审美，无大团队，追求个人表达 | 角色一致性、电影感、全流程效率 | 高 |
| 短视频内容团队（2-5人） | MCN/自媒体，需批量产出剧情号内容 | 模板复用、协作分工、多语种出海 | 中高 |
| 营销/广告创意人 | 品牌方/Agency，需快速出概念片和分镜预演 | 风格迁移、导演风格模仿、快速迭代 | 高 |
| AI 创作爱好者 | 技术尝鲜者，喜欢探索新工具 | 多模型切换、社区分享、模板交易 | 中低 |

### 2.2 核心使用场景

1. **灵感→成片**：创作者有一个想法（"一个宇航员在火星上遇见童年的自己"），希望 30 分钟内得到一支 60 秒的概念短片
2. **批量剧情号生产**：团队每周需产出 10 条竖屏剧情短视频，希望复用模板和角色设定
3. **广告预演**：创意人需要在提案前快速生成导演风格参考片，向客户展示视觉方向
4. **出海内容本地化**：已生成中文短片，需快速配英语/日语旁白和字幕

## 三、问题与机会

### 3.1 当前痛点

| 痛点 | 严重度 | 现有方案不足 |
|------|--------|-------------|
| 角色跨镜头不一致 | ★★★★★ | Runway/Pika 单镜头生成尚可，多镜头角色漂移严重 |
| 创作流程碎片化 | ★★★★☆ | 剧本用 ChatGPT、生成用 Runway、配音用 ElevenLabs、字幕用剪映，工具切换成本高 |
| 缺乏叙事结构指导 | ★★★☆☆ | 现有工具只做单镜头生成，不帮用户构建完整故事弧 |
| 风格模仿不可控 | ★★★☆☆ | 风格迁移停留在滤镜层面，无法模仿导演的镜头语言和叙事节奏 |
| 协作能力缺失 | ★★★☆☆ | 个人工具为主，团队分工（编剧/分镜/配音）无法在线协作 |

### 3.2 机会判断

- AI 视频模型能力在 2026 年已达到可用拐点（单镜头 5-10 秒，质量可接受）
- 市场上缺乏"全链路 + 角色一致性"的整合方案，多数玩家只做单点
- 短剧/微短剧市场爆发，对低成本、高效率的 AI 辅助工具有真实需求
- **关键假设**：角色一致性可以通过"角色锁定 + 参考图注入 + 后处理对齐"的工程方案在 MVP 阶段达到 70% 可用度

## 四、MVP 范围（P0）

> MVP 目标：验证"想法→剧本→分镜→生成→配音字幕"的最小闭环，核心差异化是角色一致性。

### 4.1 P0 功能清单

| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| F1 | AI 视频生成入口 | P0 | 集成 1-2 个主流模型，prompt→短片 |
| F2 | 智能剧本助手 | P0 | 一句话→完整分镜脚本（含镜头描述、台词、时长） |
| F3 | 角色/场景一致性保持 | P0 | 核心差异化，角色锁定+参考图注入 |
| F4 | 一键配音+字幕 | P0 | 生成后自动配旁白和字幕 |
| F5 | 项目管理基础 | P0 | 创建/保存/导出项目 |

### 4.2 详细需求

---

#### F1：AI 视频生成入口

**用户故事**：作为创作者，我希望输入文字描述就能生成视频片段，这样我可以快速将想法视觉化。

**触发与输入**：
- 用户在项目中点击"生成镜头"
- 输入：prompt（必填，文本）、参考图（可选，1-3 张）、时长（5s/10s，默认 5s）、分辨率（720p/1080p，默认 720p）、模型选择（默认推荐）

**系统行为**：
1. 校验 prompt 非空、免费额度充足
2. 调用视频生成 API（MVP 阶段接入 1 个主力模型 + 1 个备选）
3. 异步生成，前端展示进度（排队中→生成中→完成/失败）
4. 生成完成后自动保存到当前项目的镜头列表
5. 支持重新生成（消耗额度）

**用户可见结果**：
- 生成中的进度卡片（预计等待时间、队列位置）
- 完成后可预览的视频片段，附带生成参数
- 失败时展示错误原因和"重试"按钮

**关键规则**：
- 免费用户每日 5 次生成额度，单次最长 5s、720p
- 生成任务超时（>5 分钟）标记为失败，不扣额度
- 同一 prompt 可生成多个版本，用户选择最佳

**异常与恢复**：
- 模型 API 不可用：自动切换备选模型，提示用户"已切换至备用模型"
- 额度不足：引导至订阅页，已输入内容暂存
- 生成失败：展示具体错误（内容审核/参数错误/服务异常），内容审核失败不扣额度

**验收**：
- 给定有效 prompt 和充足额度，当用户点击生成，则 5 分钟内返回可播放视频
- 给定额度为 0，当用户点击生成，则跳转订阅页且不创建生成任务
- 给定模型 API 返回审核拒绝，当生成失败，则展示"内容不符合规范"且不扣额度

---

#### F2：智能剧本助手

**用户故事**：作为有想法但不擅长写剧本的创作者，我希望输入一句话就能得到完整的分镜脚本，这样我可以直接进入生成环节。

**触发与输入**：
- 用户在项目中点击"AI 写剧本"
- 输入：核心想法（必填，一句话）、目标时长（30s/60s/90s，默认 60s）、风格标签（可选，如"科幻""悬疑""治愈"）、目标平台（横屏电影/竖屏短视频，默认横屏）

**系统行为**：
1. 调用 LLM 生成结构化剧本，包含：
   - 故事梗概（100 字以内）
   - 角色列表（名称、外貌描述、性格关键词）
   - 分镜表（镜号、景别、画面描述、台词/旁白、时长、运镜建议）
2. 分镜数量根据目标时长自动计算（60s ≈ 8-12 个镜头）
3. 生成后用户可逐镜编辑、删除、新增
4. 支持"重新生成"和"基于反馈修改"（如"让结尾更反转"）

**用户可见结果**：
- 结构化分镜表，每镜可展开编辑
- 角色卡片（名称+外貌描述，可后续用于角色一致性锁定）
- "一键全部生成"按钮（将所有分镜送入 F1 生成队列）

**关键规则**：
- 剧本生成不消耗视频额度（仅消耗 LLM token，计入免费额度的单独配额）
- 分镜中的角色外貌描述自动同步到 F3 的角色库
- 用户编辑过的分镜在重新生成时保留（标记为"已锁定"）

**异常与恢复**：
- LLM 返回格式异常：重试一次，仍失败则展示原始文本供用户手动整理
- 生成超时（>30s）：提示"生成较慢，请稍候"，后台继续

**验收**：
- 给定"一个机器人在废弃城市里种花"和 60s，当生成剧本，则返回包含 8-12 个分镜的结构化脚本，且每个分镜有画面描述和时长
- 给定用户已编辑第 3 镜，当点击重新生成，则第 3 镜内容不变，其余镜头更新
- 给定剧本中包含 2 个角色，当生成完成，则角色库中自动创建对应角色卡片

#### F3：角色/场景一致性保持（核心差异化）

**用户故事**：作为创作者，我希望同一个角色在多个镜头中保持外貌一致，这样我的短片才有连贯的叙事感，而不是每镜换一个人。

**触发与输入**：
- 方式 A（从剧本导入）：F2 生成剧本后，角色卡片自动创建，用户上传 1-3 张角色参考图完成"角色锁定"
- 方式 B（手动创建）：用户在角色库中新建角色，填写名称、外貌描述、上传参考图
- 场景锁定同理：创建场景卡片，上传参考图/填写环境描述

**系统行为**：
1. **角色锁定流程**：
   - 用户上传参考图（正面/侧面/全身，至少 1 张）
   - 系统提取角色特征向量（人脸/体型/服装/发色）
   - 生成该角色的"角色 ID"，存储特征向量和参考图
2. **生成时注入**：
   - 用户在分镜中选择"出场角色"（可多选）
   - 生成 prompt 自动拼接角色描述 + 参考图作为 image reference
   - 后端调用支持 image-to-video / reference-based generation 的模型
3. **后处理对齐**（MVP 简化版）：
   - 对生成结果做人脸检测，与角色特征向量比对
   - 相似度低于阈值（默认 0.65）时标记"一致性低"，建议重新生成
   - 不做复杂的人脸替换（P1 再做）

**用户可见结果**：
- 角色库页面：角色卡片（头像、名称、描述、锁定状态）
- 分镜编辑时：角色选择器，已锁定角色显示"✓ 已锁定"徽章
- 生成结果上：一致性评分标签（高/中/低），低分提示"角色可能有偏差"

**关键规则**：
- MVP 阶段每个角色至少需要 1 张参考图才能锁定
- 角色一致性不保证 100%，产品文案需明确"AI 生成存在不确定性，建议多生成几版选择"
- 场景锁定同理，支持"室内/室外/特定地点"描述
- 角色/场景数据存储在用户项目空间，跨项目可复用

**异常与恢复**：
- 参考图无人脸/主体不清晰：提示"未能识别清晰主体，请上传更清晰的图片"
- 模型不支持参考图注入：降级为纯 prompt 生成，提示"当前模型不支持角色锁定，已使用文字描述"
- 一致性检测服务不可用：跳过评分，正常返回视频

**验收**：
- 给定用户已锁定角色 A（含 2 张参考图），当在 3 个分镜中选择角色 A 并生成，则 3 个视频中角色外貌具有可辨识的一致性（人工评估 ≥ 2/3 镜头可认出同一人）
- 给定用户上传模糊图片，当创建角色，则提示"未能识别清晰主体"且不创建锁定
- 给定当前模型不支持参考图，当生成含锁定角色的分镜，则降级为文字描述并提示用户

#### F4：一键配音+字幕

**用户故事**：作为创作者，我希望生成视频后自动配上旁白和字幕，这样我不需要再切换到其他工具做后期。

**触发与输入**：
- 用户在项目页面点击"一键配音字幕"
- 系统自动从分镜脚本中提取台词/旁白文本
- 用户可选择：配音语言（中/英/日，默认中文）、音色（3-5 种预设，默认"沉稳男声"）、字幕样式（底部居中，默认）

**系统行为**：
1. 从分镜脚本提取每镜的台词/旁白文本
2. 调用 TTS API 生成对应音频片段
3. 将音频按分镜时间轴拼接到视频音轨
4. 生成 SRT 字幕文件，自动匹配时间轴
5. 烧录字幕到视频（可选，默认开启）
6. 输出最终成片（MP4，含音轨和字幕）

**用户可见结果**：
- 配音预览：可逐句试听，调整音色和语速
- 字幕预览：可编辑字幕文本、调整显示时间
- 最终成片：可下载 MP4 + SRT 文件

**关键规则**：
- 配音消耗单独额度（免费用户每月 10 分钟配音时长）
- 支持仅配音不烧字幕、仅字幕不配音
- 字幕语言可与配音语言不同（如中文配音+英文字幕，服务出海）
- MVP 阶段音色为预设，不支持声音克隆（P1）

**异常与恢复**：
- TTS 服务失败：保留视频，提示"配音生成失败，可下载无配音版本"
- 字幕文本为空（分镜无台词）：提示"当前剧本无台词，是否添加旁白？"
- 音视频合成失败：分别提供视频文件和音频文件下载

**验收**：
- 给定含 5 句台词的 60s 短片，当点击一键配音（中文），则输出含中文旁白和中文字幕的 MP4，字幕与语音同步误差 < 0.5s
- 给定分镜无台词，当点击一键配音，则提示"无台词"且不生成音频
- 给定 TTS 服务异常，当配音失败，则仍可下载原视频且不扣配音额度

#### F5：项目管理基础

**用户故事**：作为创作者，我希望我的创作过程可以保存和继续，这样我不需要一次完成所有工作。

**功能点**：
- 创建项目（名称、封面、创建时间）
- 项目内包含：剧本、角色库、场景库、镜头列表、成片
- 自动保存（每 30 秒或每次操作后）
- 导出：成片 MP4、分镜脚本 PDF、角色设定表
- 项目列表页：展示所有项目，支持搜索和排序

**验收**：
- 给定用户创建项目并生成 3 个镜头，当刷新页面，则项目和镜头数据完整保留
- 给定用户点击导出成片，则下载 MP4 文件且可正常播放

## 五、差异化功能（P1/P2，非 MVP）

### 5.1 P1：风格迁移工坊

- 上传参考图/电影截图，分析视觉风格（色调、构图、光影、镜头运动）
- 生成风格描述向量，注入到视频生成 prompt
- 预设导演风格包：诺兰（冷峻、IMAX 构图、时间非线性）、韦斯·安德森（对称构图、高饱和、复古色调）、王家卫（手持、抽帧、霓虹色调）等
- **MVP 不做**：MVP 阶段仅支持通过 prompt 描述风格，不做自动风格分析

### 5.2 P1：协作共创空间

- 多人实时协作同一项目（类似 Google Docs）
- 角色分工：编剧（编辑剧本）、分镜师（调整镜头）、配音师（选择音色）
- 评论和批注功能
- 版本历史和回滚
- **MVP 不做**：MVP 为单人工具，协作在验证核心闭环后启动

### 5.3 P2：AI 影评社区

- 用户上传作品，AI 自动分析：
  - 镜头语言（景别分布、运镜类型、剪辑节奏）
  - 叙事结构（三幕式/英雄之旅/非线性）
  - 情感曲线
  - 给出专业级反馈和改进建议
- 社区展示、点赞、评论
- **MVP 不做**：社区功能在用户量达到阈值后启动

### 5.4 P2：模板市场

- 热门短视频模板（开箱、Vlog、剧情反转、产品展示等）
- 一键复用：替换文本/角色/素材即可生成
- 创作者可上传模板，获得分成
- **MVP 不做**：MVP 阶段提供 3-5 个内置模板（硬编码），不做交易市场

## 六、商业化设计

### 6.1 定价模型（草案，需验证）

| 维度 | 免费版 | 基础版（¥99/月） | 专业版（¥299/月） | 团队版（¥799/月） |
|------|--------|-----------------|------------------|------------------|
| 视频生成 | 5 次/天 | 100 次/月 | 500 次/月 | 2000 次/月 |
| 单次时长 | 5s | 10s | 15s | 15s |
| 分辨率 | 720p | 720p | 1080p | 1080p |
| 角色锁定 | 3 个角色 | 10 个角色 | 无限 | 无限 |
| 配音时长 | 10 分钟/月 | 60 分钟/月 | 300 分钟/月 | 1000 分钟/月 |
| 协作人数 | 1 | 1 | 3 | 10 |
| 模板/风格包 | 基础 | 全部免费 | 全部免费 | 全部免费 |
| 水印 | 有 | 无 | 无 | 无 |

### 6.2 模板/风格包付费

- 单个风格包：¥9.9-29.9（导演风格、电影质感 LUT 等）
- 单个模板：¥4.9-19.9
- 创作者分成：70%
- **MVP 阶段**：不接入支付，所有内容免费，先验证使用量

### 6.3 商业化关键假设

- 免费→付费转化率目标：5%（行业 SaaS 平均 3-8%）
- 核心付费驱动：生成额度不足 + 去水印 + 高分辨率
- 需验证：用户是否愿意为"角色一致性"这一差异化功能支付溢价

## 七、关键指标

### 7.1 北极星指标

**每周完成成片导出的项目数**（反映核心闭环价值）

### 7.2 辅助指标

| 类别 | 指标 | 目标（MVP 上线后 3 个月） |
|------|------|--------------------------|
| 获客 | 注册用户数 | 5,000 |
| 激活 | 首日创建项目率 | > 40% |
| 留存 | 次周留存 | > 25% |
| 核心行为 | 人均生成镜头数 | > 5 |
| 核心行为 | 角色锁定使用率 | > 30% |
| 完成 | 项目导出率 | > 15% |
| 满意度 | NPS | > 30 |

### 7.3 指标口径说明

- "完成成片导出"：用户成功下载含配音+字幕的最终 MP4
- "角色锁定使用率"：创建了至少 1 个锁定角色的用户 / 活跃用户
- 以上目标为初始假设，上线后根据实际数据校准

## 八、技术依赖与风险

### 8.1 外部依赖

| 依赖 | 用途 | 风险 | 缓解 |
|------|------|------|------|
| 视频生成 API（Runway/Pika 等） | F1 核心 | API 不稳定、价格变动、审核严格 | 接入 2 个模型做降级，抽象统一接口 |
| LLM API | F2 剧本生成 | 输出格式不稳定 | 结构化 prompt + 重试 + 容错解析 |
| TTS API | F4 配音 | 音色质量、多语言支持 | 接入 2 家 TTS，预设音色精选 |
| 人脸特征提取 | F3 一致性 | 准确率、隐私合规 | 本地处理或合规第三方，用户数据加密 |

### 8.2 核心风险

| 风险 | 等级 | 应对 |
|------|------|------|
| 角色一致性效果不达预期 | 高 | MVP 明确标注"Beta"，管理用户预期；P1 引入人脸替换后处理 |
| 视频生成成本过高 | 高 | 免费额度严格控制；优化 prompt 减少重试；探索自部署小模型 |
| 内容合规风险 | 高 | 接入内容审核，生成前+生成后双重过滤；建立举报机制 |
| 多模型接口差异大 | 中 | 设计统一的 VideoProvider 抽象层，新模型接入只需实现适配器 |
| 用户留存低 | 中 | MVP 聚焦核心闭环，不堆砌功能；通过模板降低首次创作门槛 |

## 九、Roadmap

### Now（MVP，0-3 个月）

**目标结果**：验证"想法→成片"核心闭环，角色一致性达到可用水平

- F1 AI 视频生成（1-2 个模型）
- F2 智能剧本助手
- F3 角色/场景一致性（基础版：参考图注入 + 一致性评分）
- F4 一键配音+字幕（3 种语言、预设音色）
- F5 项目管理基础
- 3-5 个内置模板
- 免费额度机制（无支付）

**进入条件**：技术选型完成，视频生成 API 接入验证通过
**退出条件**：周活跃用户 > 500，项目导出率 > 10%，NPS > 20

### Next（P1，3-6 个月）

**目标结果**：提升创作质量和团队协作能力，开始商业化

- 风格迁移工坊（自动风格分析 + 导演风格包）
- 协作共创空间（多人实时协作）
- 角色一致性增强（人脸替换后处理，一致性 > 85%）
- 声音克隆（用户上传声音样本）
- 接入支付，启动订阅制
- 模板市场（创作者上传+分成）

**进入条件**：MVP 留存数据验证核心价值，用户有明确的协作和风格需求
**退出条件**：付费转化率 > 3%，团队版有首批付费客户

### Later（P2，6-12 个月）

**目标结果**：构建社区生态，成为 AI 短片创作的首选平台

- AI 影评社区
- 更多模型接入（含开源模型自部署）
- 移动端适配
- API 开放平台
- 创作者激励计划

## 十、非目标（本期明确不做）

1. **不做直播/实时生成**：技术不成熟，且与核心叙事创作场景不符
2. **不做 3D 建模/动画**：聚焦 AI 视频生成，不扩展到 3D 工作流
3. **不做专业剪辑时间线**：MVP 阶段生成即成片，不做复杂剪辑；P1 可考虑基础剪辑
4. **不做音乐生成**：配音聚焦人声旁白，BGM 采用免版权音乐库（P1 考虑 AI 音乐）
5. **不做移动端 App**：MVP 为 Web 端，移动端在用户量验证后考虑
6. **不做自研视频生成模型**：MVP 阶段全部调用第三方 API，聚焦应用层体验
