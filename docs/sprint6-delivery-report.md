## 二、功能详情

### R12 团队协作空间
- **Team 模型**：名称、简介、所有者、成员列表、项目列表
- **角色与权限**：
  - owner（所有者）：管理团队/成员、增删改项目
  - editor（编辑者）：创建/编辑项目
  - viewer（查看者）：仅查看
  - 权限经 `can(userId, permission)` 统一判定
- **团队管理**：创建、更新、列表（可按成员过滤）
- **成员管理**：邀请成员、修改角色、移除成员（所有者不可改/不可移除）
- **项目共享**：项目加入团队（Project 新增 teamId），团队项目列表
- **前端团队工作台**：
  - `#/teams` 团队列表 + 创建团队
  - `#/team/:id` 团队详情：成员列表（角色下拉/移除）、添加成员、团队项目、添加项目

## 六、已知限制与后续建议

1. **成员邀请为 ID 直接添加**：当前通过输入 userId 添加，暂无邀请链接/邮件通知/审批流。
2. **无实时协同编辑**：多人同时编辑同一项目仍可能覆盖，可后续引入操作锁或 CRDT。
3. **团队级权限粒度较粗**：按团队角色统一控制，暂不支持按项目/按镜头单独授权。
4. **团队无用量/计费归集**：团队成员各自消耗额度，暂无团队共享额度池与企业账单。
5. 其余历史限制保持不变。
