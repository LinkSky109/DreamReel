## 一、LibTV 产品快照

从首页抓取到的核心信息：

- **模型矩阵**：Minimax H3 / MaxWan 3.0 / Seedance 2.5（国产三强）
- **五合一画布**：视频生成 / 图片生成 / 音频生成 / 剧本生成 / 智能剪辑
- **独家能力**（首页角标）：
  - 剧本原创与改编
  - 导演执导
  - 角色造型室
  - 创意片头
- **内容分类**：TV Show / 剧场计划 / 精选画布 / 专业影视 / 短剧 / 漫剧 / 商业广告 / 动漫游戏 / 教育 / 生活

## 六、关键判断与取舍

1. **不照搬 LibTV 信息架构**：LibTV 是面向 C 端用户的"打开就能玩"产品，DreamReel 当前是偏专业创作者的工作台。五 tab 同画布会稀释编辑器深度，本期不做。
2. **国产 Provider 只做适配层，不做模型调优**：Seedance/Minimax/Wan 都走 OpenAI 兼容或官方 SDK 风格接口，配置 Key 即可切换；真实模型质量由官方保证。
3. **改编不做版权校验**：MVP 阶段只接受用户粘贴文本，版权责任由用户承担；后续可接正版 IP 库。
4. **造型室只做文本字段，不做图生图**：服装/妆容/造型以 prompt 描述形式注入视频生成；后续可接 LoRA 形象生成。
5. **复刻保留 remixOf 溯源**：新项目记录来源 projectId 和原作者，便于后续分成/署名。
