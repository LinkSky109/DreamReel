## 二、功能详情

### R09 作品广场与社交
- Project 模型新增：isPublished / publishedAt / likeCount / viewCount / galleryCategory / challengeId
- 发布 / 下架作品到广场
- 广场流：7 大分类（全部/故事短片/产品广告/旅行Vlog/知识科普/音乐/社媒推广）
- 排序：最新发布、最多点赞（综合点赞与播放热度）
- 播放统计（viewCount）、点赞 toggle（内存 Map 记录用户，防重复点赞）
- 作品卡片：预览/播放图标、作者、点赞数、播放数
- 点击作品记录播放并进入项目；点击作者跳转创作者主页

### R10 创作挑战与活动
- 3 个官方挑战：🌙 梦境重塑、🏙️ 城市微光、🚀 60 秒科幻
- 每个挑战含主题、描述、参赛规则、奖励、起止周期、状态
- 一键参与：基于挑战主题自动创建投稿项目并关联 challengeId
- 投稿：将项目发布并关联到挑战
- 挑战详情：含按热度排序的作品排行榜（🥇🥈🥉）

## 五、已知限制与后续建议

1. **点赞记录在内存**：重启后点赞关系（防重复）重置，仅 likeCount 持久化；可后续写入 storage。
2. **挑战为内置静态数据**：暂不支持运营在后台动态创建挑战；可扩展挑战管理后台。
3. **作品广场无评论/关注/信息流推荐**：当前为分类 + 简单热度排序，后续可加关注流、个性化推荐、评论互动（R09 增强）。
4. **播放统计较粗**：点击即记一次播放，未做去重与停留时长校验。
5. 其余历史限制（真实模型接入、BGM 素材、海报/预告片成品导出等）保持不变。
