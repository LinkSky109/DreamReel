# DreamReel Provider 扩展分析（用户给定）

## 一、视频生成模型

### 质量优先
1. **Doubao Seedance 2.5**（`doubao-seedance-2-5-260628`）— 写实/古风漫剧首选
   - 火山方舟 ARK 国内 API
   - 单镜头最长 30s
   - 支持最多 30 张人设参考图锁定角色长相
   - 支持音频参考联动口型
   - 支持时间戳局部画面编辑、视频续片
   - 最高 1080p 24fps
   - 中文提示词理解强，长叙事连贯
   - 短板：日系二次元弱于 Pika；复杂高速打斗肢体容易崩坏；计费额度消耗高

2. **Pika 3.0** — 二次元/日系漫画首选
   - 二次元画风天花板，漫画质感强
   - 运镜自然，镜头氛围感好
   - 短板：API 准入排队；单镜头短（3-6s）；多镜头人物漂移

3. **Runway Gen-3** — 备选写实向
   - 画面运动流畅，图片转视频能力强
   - 短板：人物一致性差，价格贵；二次元弱

### 成本优先（草稿预览）
4. **Minimax** — 国内直连，便宜，快速跑脚本小样
   - 短板：动态幅度小，动作崩坏多

5. **Doubao Seedance 2.0 Fast** — 低成本国内备选
   - 480p 快速预览，最长 15 秒
   - 比 2.5 便宜
   - 短板：画面质感、人物一致性弱于 2.5

### 生产策略
- 草稿全部 Minimax / Seedance 2.0 Fast
- 定稿写实镜头上 Seedance 2.5
- 二次元定稿上 Pika

## 二、剧本生成（LLM）

### 质量优先
1. **Claude 3.5 Sonnet** — 长篇连续剧本首选
   - 超大上下文，长篇故事人设稳定
   - 适合一次性写多集漫剧剧本
   - 短板：海外 API，需要海外支付

2. **GPT-4o** — 分镜拆解、生成视频 Prompt 首选
   - 指令遵循强，擅长输出 JSON 结构化分镜
   - 短板：长故事连贯性不如 Claude；海外 API

3. **Doubao Evolving**（豆包深度思考）— 国内主力备选
   - 火山方舟 ARK 国内 API
   - 超长上下文，中文语感强
   - 擅长写国产古风/都市漫剧剧本
   - 可同时完成剧本 + 分镜 JSON 输出
   - 短板：极致创意略弱于 GPT-4o/Claude；日系二次元风格塑造不如海外模型

### 成本优先
4. **Minimax 01** — 国内兜底草稿剧本
   - 便宜，出稿快
   - 短板：长篇剧情逻辑容易跑偏

5. **GPT-4o-mini** — 轻量任务：字幕校对、小修改

### 生产策略
- 海外链路：Claude 写完整剧本 → GPT-4o 拆分成分镜 & 视频 prompt
- 纯国内链路：Doubao Evolving 一次性完成【剧本撰写 + 拆分成分镜 + 生成 Seedance2.5 的提示词】

## 三、配音 TTS

### 质量优先
1. **ElevenLabs v2/Turbo** — 情绪对话首选
   - 角色情绪丰富，停顿自然，喜怒哀乐表现力极强
   - 支持声音克隆
   - 短板：海外 API，按量计费，成本偏高

2. **Doubao Seed-TTS 2.0**（`seed-tts-2.0`）— 国内主力备选
   - 火山方舟 ARK 国内 API
   - 中文自然度高；支持对话式 TTS
   - 支持声音复刻；支持流式合成
   - 价格远低于 ElevenLabs
   - 可直接配合 Seedance2.5 音频参考，引导视频口型匹配
   - 短板：极致细腻情绪表现力略弱于 ElevenLabs

### 成本优先
3. **Minimax TTS** — 国内低成本兜底
   - 音色多，价格便宜
   - 短板：情绪起伏弱，对话容易平淡

4. **OpenAI TTS tts-1-hd** — 仅适合旁白，不适合角色对话

### 生产策略
- 成片预算充足：ElevenLabs
- 纯国内链路：Doubao Seed-TTS 2.0，配合 Seedance 2.5 音频参考功能提升口型同步

---

## 四、两套完整生产流水线

### 方案 A：最高质量混合链路（海外方案 + Seedance 2.5）
- 剧本：Claude 3.5 Sonnet
- 分镜 & 视频 Prompt：GPT-4o
- 视频渲染：写实镜头 Seedance 2.5｜二次元镜头 Pika
- 配音：ElevenLabs
- 字幕校对：GPT-4o-mini

### 方案 B：纯国内全 API 链路，无海外依赖（强烈推荐备选）
- 剧本 + 分镜 + 视频提示词：Doubao Evolving
- 视频渲染：Doubao Seedance 2.5
- 配音：Doubao Seed-TTS 2.0
- 字幕校对：Doubao Evolving（轻量调用）
- 全部火山方舟 ARK + Minimax，不需要海外密钥
